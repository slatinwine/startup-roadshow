# 创业路演模拟器 · 文字冒险

一款单文件 AI 文字冒险游戏：你扮演创业者，自由打字做决策，由 AI 主持人「老K」——一位毒舌犀利的创业老江湖——依真实市场行情判定真伪与可行性，历经 8 个经营季度后站上路演台接受投资人拷问。

## ✨ 功能特性

- 聊天式自由冒险：一切决策靠自由输入文字，AI 叙述剧情并按现实常识判定效果
- 经营状态系统：资金、产品完成度、用户规模、团队士气、市场口碑五维数值实时变化
- 8 季度节奏与突发事件：第 2/4/6/8 季度触发竞品、政策、舆情等事件；每个决策附 0-100 可行性评分
- 务实事项追问：按季度追问工商注册、记账报税、ICP 备案、代码合规等早期创业绕不开的事
- 路演终局：8 季度后进入投资人 Q&A，逐题打分，最终给出多位投资人的点评与结局
- 双 AI 通道：WorkBuddy 云端域名下免密钥直玩；其他域名（如 GitHub Pages）可在页面右上角「Key」按钮中配置自备 API Key
- 移动端适配：动态视口高度、防 iOS 聚焦放大等手机端细节处理

## 🚀 使用方法

1. 用浏览器直接打开 `index.html`
2. 若在 WorkBuddy 云应用域名下打开，AI 自动就绪，开箱即玩
3. 若在 GitHub Pages 等其他域名打开：点击右上角「Key」按钮，填写 OpenAI 兼容接口的 Base URL、API Key 与模型名（推荐智谱 GLM：`open.bigmodel.cn/api/paas/v4`，模型 `glm-4-flash`）。Key 只保存在本机浏览器 localStorage，不会上传

## 🛠️ 技术栈

- HTML / CSS / 原生 JavaScript（单文件）
- WorkBuddy Cloud SDK（云端免密钥 LLM 调用，流式输出）
- 自备 Key 模式：OpenAI 兼容 Chat Completions 接口（SSE 流式）
